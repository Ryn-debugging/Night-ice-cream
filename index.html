      Kredit & Panduan

      NIGHT SHIFT: ICE CREAM

      Game horror psikologis 2D berbasis browser tentang simulasi jaga kios tengah malam, observasi detail, dan ketegangan mengambil keputusan di balik kaca.

      Kontrol Lengkap

      • Klik Kiri — Semua tombol UI, jendela kios, telepon merah, saklar lampu, & freezer
      • E — Buka / tutup jendela pelayanan (termasuk banting tutup darurat!)
      • Q — Buka / tutup menu observasi pelanggan
      • R — Tolak pelayanan pelanggan
      • T — Angkat telepon kios saat berdering
      • F — Nyalakan / matikan lampu teras & reset neon berkedip
      • 1 – 5 — Ambil varian es krim (Vanila, Cokelat, Stroberi, Matcha, Mint)
      • Enter — Serahkan pesanan es krim
      • J — Buka buku catatan petunjuk
      • Space — Lanjutkan / percepat teks dialog
      • Esc — Jeda permainan / tutup panel

      Teknologi

      HTML5 · Vanilla CSS3 · Vanilla JavaScript · HTML5 Canvas 2D · Web Audio API (Procedural) · localStorage (100% Offline)
